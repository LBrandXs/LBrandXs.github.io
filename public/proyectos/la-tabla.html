Sistema Restaurante — La Tabla

Plataforma de restaurante por microservicios: administración, pedidos, reservas, reportes, panel web y app móvil para clientes.

.NET 8 Node.js React React Native / Expo MongoDB Docker

Resumen

La Tabla digitaliza la operación diaria de un restaurante: toma de pedidos, gestión de mesas y reservas, cocina y reportes de ventas, todo coordinado entre varios microservicios desplegados con Docker sobre un monorepo compartido.

Funcionalidades clave

Gestión de pedidos

Flujo completo desde que se toma el pedido en mesa hasta que se marca como entregado y facturado.

Reservas de mesas

Control de disponibilidad y reservas para evitar sobreocupación en horas pico.

Reportes de ventas

Panel con métricas de ventas por período, producto y mesero para el equipo administrativo.

App móvil para clientes

Cliente en React Native/Expo (documentado como "Microservicio 6") para pedidos desde el celular.
