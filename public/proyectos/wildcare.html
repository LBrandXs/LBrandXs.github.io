WildCare

Sistema de escritorio para gestión veterinaria: clientes, mascotas, citas, historiales médicos, recetas, vacunación y facturación.

Java JavaFX MySQL

Resumen

WildCare es una aplicación de escritorio pensada para clínicas veterinarias pequeñas que necesitan llevar el control de sus pacientes sin depender de hojas de cálculo. Centraliza el registro de clientes y mascotas, el historial clínico y la facturación en una sola interfaz de escritorio.

Aplicación de escritorio

Funcionalidades clave

Ficha de mascota

Historial médico completo por mascota: consultas, diagnósticos y tratamientos anteriores.

Agenda de citas

Programación y seguimiento de citas por cliente y por mascota.

Cartilla de vacunación

Registro de vacunas aplicadas con fechas para dar seguimiento a refuerzos.

Facturación

Generación de recetas y facturas ligadas a cada consulta.

Stack técnico

  • Java
  • JavaFX
  • MySQL
  • JDBC

Mi rol

Diseño y desarrollo individual: modelado de la base de datos, interfaz JavaFX y lógica de negocio para citas, historiales y facturación.
