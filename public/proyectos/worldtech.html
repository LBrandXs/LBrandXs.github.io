WorldTech

Sitio web informativo sobre tecnología: gadgets, comparativas de productos y novedades del sector.

HTML5 CSS3 JavaScript

Resumen

WorldTech es un sitio informativo enfocado en tecnología de consumo: reseñas de gadgets, comparativas de productos y artículos sobre novedades del sector, construido con HTML, CSS y JavaScript puro.

Funcionalidades clave

Catálogo de artículos

Comparativas de producto

Secciones dedicadas a comparar especificaciones entre productos similares.

Diseño responsive

Interfaz adaptada a distintos tamaños de pantalla sin depender de un framework.
