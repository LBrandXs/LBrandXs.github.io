Juego del Ahorcado

Clásico juego de palabras con 3 niveles de dificultad y dibujo animado del muñeco usando Canvas API.

HTML5 CSS3 JavaScript Canvas API

Resumen

Implementación del clásico juego del ahorcado en el navegador, con tres niveles de dificultad (que ajustan el largo/complejidad de las palabras) y el dibujo del muñeco animado directamente sobre un canvas conforme se acumulan los errores.

El juego

Funcionalidades clave

3 niveles de dificultad

Selección de nivel que cambia el banco de palabras y la cantidad de intentos permitidos.

Dibujo animado en Canvas

El muñeco del ahorcado se dibuja progresivamente con la API de Canvas en cada error.

Validación de letras

Control de letras ya usadas y detección de victoria/derrota en tiempo real.

Stack técnico

  • HTML5
  • CSS3
  • JavaScript
  • Canvas API

Mi rol

Desarrollo individual completo: lógica del juego, dibujo en canvas y estilos.
