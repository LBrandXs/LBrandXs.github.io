Sistema Bancario — NexusBank

Plataforma bancaria por microservicios con doble partida contable, panel web administrativo y app móvil para clientes, desplegada en producción.

.NET 8 Node.js React React Native PostgreSQL MongoDB Docker

Resumen

NexusBank simula la operación de un banco digital: apertura de cuentas, transferencias, historial de movimientos y control contable con doble partida para que cada transacción quede balanceada del lado del banco y del cliente. Se construyó como monorepo de microservicios, cada uno con su propia base de datos, coordinados vía API Gateway.

Funcionalidades clave

Doble partida contable

Cada transacción genera asientos balanceados (débito/crédito) para mantener la integridad financiera del sistema.

Transferencias entre cuentas

Validación de saldo, límites y estado de cuenta en tiempo real antes de confirmar cualquier movimiento.

Panel web administrativo

Vista para operadores del banco: gestión de cuentas, clientes y reportes de actividad.

App móvil para clientes

Cliente construido en React Native/Expo para consultar saldo, movimientos y realizar transferencias.
